## 一句话结果

目的端负载低于理论上限的 165 次运行全部收敛；只有 `40% hotspot × 0.04 injection rate` 使目的端负载达到 1.024 flits/cycle 并越过上限，此时三种配置都明显恶化，但停止状态不同，因此只能报告为有限压力实验，不能当作稳态性能排名。
